# 잠긴 도자기 공방

미술 교과서 **「11. 쓰임과 아름다움」**을 펼쳐 보며 문제를 푸는 3D 방탈출 게임입니다.
학기 초에 학생들이 미술 교과서를 직접 넘겨 보게 하는 것이 목적입니다.

> 도예가 선생님의 공방에 견학을 왔는데, 문이 모두 잠겨 버렸어요.
> 교과서에서 정답을 찾아 다섯 방을 지나 공방을 탈출하세요!

## 게임 구성

| 단계 | 방 | 교과서 단원 | 문제 |
|:---:|---|---|---|
| 1 | 흙을 빚는 방 | 빚어서 구워내다 › 도자의 성형 방법 | 작품 4점의 성형 방법 맞히기 (핀칭 · 코일링 · 판 성형 · 물레 성형) |
| 2 | 불을 다루는 가마실 | 빚어서 구워내다 › 도자의 제작 과정 | 작업 일지 6장을 읽고 제작 과정 순서 맞추기 + 재벌구이 온도 입력 |
| 3 | 무늬를 입히는 장식실 | 빚어서 구워내다 › 도자의 장식 기법 | 도자기 4점의 장식 기법 맞히기 (상감 · 철화 · 귀얄 · 인화) |
| 4 | 이름을 짓는 전시실 | 도자의 종류 · 내 이름을 맞혀 봐! | 종류 → 장식 → 문양 → 형태 순서로 도자기 이름표 만들기, 달항아리 문제 |
| 5 | 공예 수장고 | 물들이고 덧붙이고 꼬다 · 끊고 자르고 두드리다 · 나전 칠기 · 새로워진 현대 공예 | 나전 칠기, 조각보, 천연 염료, 경상, 지승 공예, 3D 프린팅 공예 문제 6개 |

방의 문제를 모두 풀면 출구 문이 열리고 다음 방으로 넘어갑니다. 5번 방까지 풀면 탈출 성공 화면에서 걸린 시간, 힌트 사용 횟수, 활동지 과제가 나옵니다.

## 조작 방법

- **둘러보기**: 화면을 끌어서 360도로 회전합니다 (키보드 방향키도 가능).
- **확대·축소**: 두 손가락으로 벌리거나 오므리고, PC에서는 마우스 휠을 씁니다.
- **조사하기**: 떠 있는 표시를 누릅니다.
  - **?** (금색): 풀어야 하는 문제
  - **◎** (초록색): 문제를 푸는 데 도움이 되는 단서
- **힌트**: 오른쪽 위 `힌트` 버튼을 누릅니다. 방마다 3단계가 있고, 본 횟수가 기록에 남습니다.
- **교과서 안내**: 모든 문제 카드에 답이 실린 교과서 소단원 제목이 함께 나옵니다.

## 수업 활용 안내

- **권장 환경**: 태블릿 가로 화면 또는 PC, 모둠당 기기 1대, 미술 교과서 필수
- **소요 시간**: 약 20~25분
- **진행 저장**: 같은 기기·브라우저에서는 진행 상황이 자동으로 저장되어 `이어 하기`로 계속할 수 있습니다.
- **마무리 활동**: 탈출 화면에서 "교과서 11단원에서 가장 갖고 싶은 공예품을 골라 재료와 기법을 활동지에 적기" 과제를 안내합니다.

## 관리자 모드 (교사용)

첫 화면 오른쪽 아래, 또는 게임 중 오른쪽 위의 **열쇠 아이콘**을 누르고 비밀번호를 입력합니다.
(비밀번호는 담당 선생님께 따로 안내받으세요.)

- **방 바로가기**: 1~5번 방으로 바로 이동하고, 모든 문이 열려 있습니다.
- **정답표 보기**: 다섯 방의 문제와 정답을 한 화면에서 확인합니다.
- 관리자 모드에서는 타이머와 진행 기록이 저장되지 않아 학생 기록에 영향을 주지 않습니다.
- `관리자 모드 끝내기`를 누르면 처음 화면으로 돌아갑니다.

> 비밀번호는 파일 안에 암호화된 값으로만 들어 있지만, 웹 페이지 특성상 완벽한 보안 장치는 아닙니다.
> 수업 중 학생이 실수로 정답을 보는 것을 막는 용도로 사용하세요.

## 배포 및 실행

- 파일 하나(`index.html`)로 동작합니다.
- 3D 그래픽(three.js r128)과 글꼴(Google Fonts)을 인터넷에서 불러오므로 **인터넷 연결이 필요**합니다.
- **GitHub Pages 배포**: 저장소 `Settings › Pages`에서 `main` 브랜치, `/ (root)` 폴더를 선택하면 `https://<아이디>.github.io/<저장소 이름>/` 주소로 열립니다.
- **로컬 실행**: `index.html`을 Chrome이나 Edge 같은 브라우저로 열면 됩니다.
